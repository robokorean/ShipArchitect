# v0.9.4.1 검사와 사용 안내

기준은 공식 v0.9.4 / 020e793 및 2026-11-25 최신 두 통합 기록입니다. 접근 가능한 GitHub에는 기존 0.9.4.1 공개 브랜치/PR이 없어 현재 공식 소스에서 분리해 요구사항을 통합했습니다. 중복 UI·인식 엔진을 새로 만들지 않았습니다.

## 구현과 안전

후보 등록의 전체 메타데이터 계산을 QThread에서 수행하며, 현재 문서와 분리한 준비 문서로 검증·공간/시설 관계·Undo와 구역을 만듭니다. 완료 시 문서 ID·revision·원본 참조가 맞고 취소되지 않았을 때만 한 번에 적용합니다. 실패·취소·문서 변경은 부분 등록을 남기지 않습니다. 원본 블록·NBT는 읽기 전용입니다. 기존 판정과 512개 공간 한도는 유지하며 외부·불완전 후보를 자동 등록하지 않습니다.

반복 ID 집합과 전체 후보 검색을 색인으로 대체하고, 중복 전체 복사와 행마다 팔레트를 스캔하는 비용을 줄였습니다. 숫자 좌표는 빠르게 복사하고, 이력의 변경 전후 스냅샷 사이에서만 변하지 않은 내용을 공유합니다. 현재 문서와 이력은 공유하지 않습니다. 튜플·독립 복사와 저장/Undo/Redo 회귀를 검사합니다. 진단 이벤트 space_registration_batch에 단계별 시간·선택/추가 수·작업 ID를 기록합니다.

대형 공간에서 **현재 선택 범위 안에서만 부분 설계**를 사용하면 실제 셀과 선택 경계의 교집합만 AI에 전달합니다. 기존 시설 전체 동작은 유지합니다. 표본/설비/경로 문맥의 생략 여부는 명시하고 Python은 표본이 아닌 정확한 셀·모든 보호 경로로 배치를 검증합니다. ‘억지로 건축하지 말고’를 포함한 사용자 원문을 회귀 테스트에 넣었습니다. 미확인 실제 재료를 돌로 바꾸지 않습니다.

## Windows 확인 순서

1. 새 폴더에 실행 ZIP 전체를 풀고 START_WINDOWS.cmd 실행 → 열기 → 기존 프로젝트 열기.
2. 공간 분석 → 검토할 후보만 선택 → 우클릭 **후보 확정·등록**. 클릭 후 진행 단계/개수가 보이고 다른 기본 UI가 응답하는지 확인합니다. 전체 후보 무검토 등록은 권장하지 않습니다.
3. 완료 전 취소 → 공간/판정/Undo에 부분 등록이 없는지 확인. 정상 완료 → Ctrl+Z/Ctrl+Y → 저장/재열기에서 원래 결과를 확인합니다.
4. 공간/시설 선택 → AI 내부 설계 → **현재 선택 범위 안에서만 부분 설계** → Shift+클릭 두 점 또는 도면/좌표로 작은 범위 지정 → 설계안 생성. 선택 교집합 바깥과 장치/NBT가 그대로인지 확인합니다.
5. 변경 검토 → 전후/수량 확인 → 승인 또는 취소. 대화 재실행·재료/JSON 수정에서도 부분 범위를 유지하는지 확인합니다.
6. 더 보기 → 오류 진단 ZIP에서 선택 건수·체감 지연·등록 실패 여부와 함께 보고합니다.

자동 GUI 검사는 Qt offscreen이며 사용자 Windows 11·RTX 3060·듀얼 모니터·V3의 실제 체감을 대신하지 않습니다. 기존 사용자 확인은 v0.9.4 기본 UI 4/4·시설 3/3·Ollama 연결 1/1 및 작은 공간의 AI 생성입니다. 승인·Undo/저장/NBT·대형 AI 설계 실사용은 별도입니다. 실제 v0.9.4.1 실사용과 완전 무정지 성능을 검증 완료로 표기하지 않습니다. 실함 정량 비교와 최종 CI 결과는 별도 검증 보고서에 기록합니다.
