# Ship Architect v0.9.4

작업 순서 중심 UI와 승인형 AI 내부 설계를 통합했습니다. 기존 공간 분석·2D/3D·시설·설비·경로·수동 편집·진단 기능은 고급 작업공간에서 유지합니다.

여러 구성 공간을 포함한 사용자 확인 시설을 한 번에 설계할 수 있습니다. Python은 정확한 셀 합집합, 기존 통로·장치/NBT 보호 및 승인 전후 변경을 검증합니다. 시설 용도와 미확정 연결을 자동 확정하지 않습니다.

실제 함선 재분석 결과와 기존 확정 공간 129개를 보존했습니다. Linux CPU의 실제 Ollama/Qwen3 연결 시험, Linux·Windows 자동 회귀 테스트와 깨끗한 폴더 독립 실행 검사를 수행했습니다. 상세 범위와 제한은 `docs/V094_DEVELOPMENT.md`를 참고하세요. 사용자 Windows 11·RTX 3060 실사용 및 대규모 자동 설계 품질은 별도 검증이 필요합니다.

실행 ZIP에는 최신 필수 소스·리소스·간결한 안내만 포함합니다. 전체를 새 폴더에 압축 해제하고 Python 3.12/3.13 환경에서 `START_WINDOWS.cmd`를 실행하세요. Ollama 모델은 별도로 준비합니다. 개인 설계도와 개발 증거는 포함하지 않습니다.
