# v0.9.4 개발 상태

2026-11-24 KST. 기준 main c80e63cb851a4917a7c2e9bba7149f1943817144 및 최신 두 개발 기록의 사용자 실사용 피드백을 반영한 개발 브랜치다.

기본 작업 순서와 다음 동작 안내, 선택 대상별 작업, 기본/고급 작업공간, 통합 변경 검토를 구현했다. 기존 리본과 컨트롤러를 고급 작업공간에서 유지한다.

AI 내부 설계는 현재 확정 공간 또는 빈 프로젝트 선택 구역의 작은 승인형 시나리오를 지원한다. 사용자 확인 시설·설비의 블록 일치 여부·미확정 경로 정보를 전달하고, 저장된 경로의 보존 구간을 Python에서 검사한다. 설계 JSON 상세 수정도 기존 검증 엔진과 미리보기·승인을 다시 거친다. 여러 공간으로 구성된 시설 전체의 동시 설계는 후속 구현 대상이다.

이 세션의 실행 환경이 시작에 실패해 실제 ship_f(1).schem·design.shipproj를 내려받아 새 코드에서 실행할 수 없었다. 실함 재분석·129개 확정 공간·NBT·성능·화면의 실사용 검증은 남아 있다. 원격 Linux·Windows CI와 합성 GUI 테스트를 통해 가능한 검사를 수행한다. Ollama 테스트는 로컬 HTTP 모의 응답이며 실제 Qwen3 모델 추론 검증은 별도다.

사용자 3.13 실사용에서 18개 중 16개 완료 보고를 확인했다. 시설 새 그룹 생성/용도 지정과 시설 편집·해제·Undo는 사용자 미확인 상태로 유지한다. 3.13의 자동 테스트 결과를 0.9.4 실함 검증으로 사용하지 않는다.

공식 릴리스와 Library 최종 실행 ZIP·기록 갱신은 실함 검증과 파일 저장이 가능한 실행 환경에서 마무리해야 한다. 이 브랜치의 preview 아티팩트는 검토용이다.
