# Ship Architect v0.9.4.1

후보 전체 선택 이후 확정·등록 클릭의 지연을 개선합니다. 등록 검증·메타데이터/Undo 준비를 백그라운드로 옮기고 진행 상태·취소·원자적 적용·문서 변경 시 폐기를 연결했습니다. 후보 판정, 기존 공간·시설 관계, 실제 블록·NBT 및 Undo/Redo를 보존합니다.

현재 선택 범위와 공간/시설의 정확한 셀 교집합에서 부분 AI 설계를 지원합니다. 큰 공간 문맥의 표본·통계 크기를 제한하고 ‘억지로 건축하지 말고’를 재료로 오인하던 문제를 수정했습니다. 실행 ZIP은 최신 필수 파일만 포함합니다.

자동 검사와 실제 Windows 사용자 PC 체감은 구분합니다. 대형 상태의 메모리 관리·화면 갱신에서 짧은 지연이 남을 수 있습니다. 실제 측정·제한 및 UI 순서는 docs/V0941_VALIDATION.md를 참고하세요.
