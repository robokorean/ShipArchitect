# Development

Runtime packages are produced only by tools/build_release.py from an explicit allowlist. Tests, tools, private inputs, logs, older archives and verification reports never enter the runtime ZIP.

Run python -m pip install -r requirements-dev.txt then python -m pytest -q. Use QT_QPA_PLATFORM=offscreen for automated Qt tests.

Private ship projects, schematics, diagnostics and screenshots must never be committed. Synthetic fixtures are generated by tools/create_v0931_demo.py. Real-file test results are retained separately.

The original legacy ZIP remains preserved outside Git. Imported v0.9.3.1 runtime and test source provides a baseline commit; v0.9.3.2 records the functional changes.

## v0.9.3.2 verification

Linux/Python 3.12: 451 automated tests passed. Qt uses the offscreen platform;
this does not certify Windows graphics drivers, physical multi-monitor behaviour,
or a live Ollama model. The connection tests use a controlled local HTTP server.
The complete ship mesh is retained during interaction; complex space fills are
deferred until release. Exterior recognition remains experimental: ambiguous
openings and merged components require review rather than automatic registration.
