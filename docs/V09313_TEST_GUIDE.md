# v0.9.3.13 확인 순서

자동 테스트는 합성 문서와 Qt 오프스크린 UI를 사용한다. 아래 실사용 확인은 사용자 Windows 11·RTX 3060·듀얼 모니터에서 별도로 수행한다.

1. ZIP을 새 폴더에 풀고 `START_WINDOWS.cmd`를 실행한다. **프로젝트 → 프로젝트 열기**로 기존 프로젝트를 열고 저장 공간을 확인한다. 기존 `design.shipproj`의 확정 공간은 129개여야 한다.
2. **프로젝트 → 공간 분석**을 누른다. 진행 상태가 갱신되고 취소할 수 있어야 한다. 원본 실함의 깨끗한 신규 분석 기준은 후보 1,974개·622,429셀이다. 사용자 제외 규칙·편집이 있다면 결과 차이를 먼저 확인한다.
3. 탐색기에서 Ctrl로 두 공간/후보를 선택하고 **우클릭 → 두 공간 경계 비교**를 실행한다. 두 ID와 실제 겹침 셀·공유 공기 경계 수가 오른쪽 속성에 나와야 한다. 선택 색상이 구분되어야 하며 비교가 공간 형상을 바꾸면 실패다.
4. **우클릭 → 선택 공간을 시설로 묶기** 또는 **공간 → 시설로 묶기**를 누르고 이름·용도를 입력하여 저장한다. 왼쪽 **시설 그룹**에 한 시설로 나타나야 한다. 원래 후보 및 확정 공간도 유지되어야 한다.
5. 시설을 선택하고 F를 누른다. 구성 공간의 범위로 카메라가 이동해야 한다. 기본 강조 수는 최대 4개, **다중 강조 (최대 32)**를 켜면 최대 32개다. 모든 구성원을 정밀 표시한다고 가정하지 않는다.
6. 시설 우클릭 **시설 이름·용도 편집**, 공간 선택 후 **기존 시설에 추가**를 확인한다. **시설 그룹 해제** 후 공간이 남아야 하고 Ctrl+Z/Ctrl+Y로 시설 해제·복원이 가능해야 한다.
7. 확정 공간을 선택하고 공통 도면의 부피를 지정한 뒤 **공간 → 분리**를 누른다. 미리보기에서 승인하고 시설의 구성원 수가 늘었는지 확인한다. Ctrl+Z로 경계와 시설 관계가 함께 복원되어야 한다.
8. 공간을 삭제할 때 확인 창의 개수를 확인한다. 시설에 남은 공간 관계가 유지되어야 한다. Undo 후 관계·형상이 돌아와야 한다. **프로젝트 → 저장** 후 다시 열어 시설·이름·경계·표시를 확인한다.
9. **분석 → 설비 분석**을 누르고 하단 **설비 전체 목록**에서 CC 컴퓨터·모뎀·Create 축 등 ID와 종류·좌표를 확인한다. 미분류와 실제 작동 미확인 상태가 유지되어야 한다. 설비 인접 후보가 포트·동력 연결 확정을 뜻하지 않아야 한다.
10. 두 내부 후보 또는 확정 공간을 선택하고 **분석 → 두 공간 경로**를 누른다. 연결 분석 후 경로 또는 불확실·차단 사유를 확인한다. 오른쪽 **구조 분석 작업공간**의 출발/도착·**경로 찾기**에서도 사용할 수 있다. 승강기 후보만으로 확정 경로를 만들면 실패다.
11. 47,425셀 대형 후보를 선택하여 마우스를 회전·이동하고 **보기 → 공통 도면**에서 Y=19·30·38로 바꾼다. 실제 함선 형상을 유지해야 한다. 준비 중 상태와 완성된 정밀 메시를 구분한다. 첫 메시 준비와 반복 프레임 속도를 별도로 관찰한다.
12. 표시 체크·숨김·고립·단면을 바꾸고 원래 상태를 복원한다. `.schem` 내보내기 후 다시 열어 블록 상태·NBT가 같아야 한다. **도구 → 오류 진단 ZIP**에서 시설·표시·캐시·실패 정보를 확인한다.

본격적인 AI 내부 설계 확대는 v0.9.4로 남긴다. 이번 버전에서도 기존 AI 미리보기·승인·재료 ID·보호 장치 검증을 사용한다. 실제 모드 충돌과 장치 작동·시설 용도는 사용자 검증을 거친다.
