# Ship Architect v0.9.3.13

Minecraft NeoForge 1.21.1 함선용 Python/PySide6 설계 편집기입니다.

1. ZIP 전체를 새 폴더에 풉니다. D 드라이브에서도 실행할 수 있습니다.
2. 64비트 Python 3.12 또는 3.13을 설치하고 `START_WINDOWS.cmd`를 실행합니다. 최초 라이브러리 설치에는 인터넷이 필요합니다.
3. **프로젝트 → 프로젝트 열기 / .schem 열기 / 새 프로젝트**에서 시작합니다.
4. **프로젝트 → 공간 분석**을 한 번 누른 뒤 탐색기에서 결과를 선택·수정하고 프로젝트를 저장합니다.

`.schem` 직접 열기는 실제 블록부터 표시합니다. `.shipproj`는 저장한 공간·시설·편집·표시 설정을 복원합니다. 분석 옵션에서 이전 결과 수동 복원, 보호 재분석, 다른 엔진 비교 및 별도 분석 저장을 사용할 수 있습니다.

## 시설과 공간 관리

- 탐색기에서 Ctrl/Shift로 공간이나 후보를 선택하고 **우클릭 → 선택 공간을 시설로 묶기**를 실행합니다. **공간 → 시설로 묶기**에서도 실행합니다. 이름과 용도를 확인한 뒤 저장합니다.
- **시설 그룹**은 여러 물리적 공간을 하나의 격납고·엔진룸 등으로 관리합니다. 후보 ID·실제 셀·기존 그룹 관계를 유지합니다. 재분석에서 구성 공간을 찾을 수 없으면 시설 속성에 재검토 참조 수를 표시합니다.
- 시설 우클릭에서 이름·용도를 편집하거나 그룹을 해제합니다. 공간을 선택한 뒤 **기존 시설에 추가**할 수 있습니다. 시설을 선택하면 구성 공간을 강조하고 F로 전체 범위에 초점을 맞춥니다. 기본 강조는 최대 4개이며 **다중 강조**로 최대 32개까지 확인합니다.
- 두 공간을 Ctrl로 선택한 뒤 **우클릭 → 두 공간 경계 비교**에서 실제 겹침과 공유 공기 경계 수를 확인합니다. 여러 선택의 강조색을 구분합니다. 공기 경계의 접촉만으로 이동 가능성을 확정하지 않습니다.
- 확정 공간의 합치기·분할은 결과 미리보기와 승인을 거칩니다. 분할된 공간의 시설 소속도 유지합니다. 삭제는 확인 후 실행하고 Ctrl+Z로 복원합니다. **시설 그룹 해제**는 포함 공간을 유지합니다.

## 설비와 이동 경로

**분석 → 설비 분석**에서 블록 ID·상태·좌표·설비 구분·소속/인접 공간을 확인합니다. CC 컴퓨터·모뎀·케이블 및 Create 축·기어·승강기 등은 ID를 기준으로 구분합니다. 연결은 6면 인접 후보이며 실제 포트·동력·장치 동작은 미확인입니다. 전체 좌표는 RLE로 보관하고 큰 목록은 페이지로 확인합니다. 미지원 모드 블록은 미분류로 유지합니다.

**분석 → 연결 분석**에서 확정 공간과 내부 후보를 출발·도착으로 선택하고 **경로 찾기**를 실행합니다. 문 상태·2칸 높이·바닥·계단 방향을 검사하는 정적 모델입니다. 벽·설비·미확인 충돌·닫힌 문·분석 범위 부족은 결과 사유를 확인하세요. Minecraft 실제 충돌과 승강기 동작은 별도 검증이 필요합니다.

## 보기와 안전

탐색기 표시 체크와 작업 선택은 독립적입니다. **보기 → 단면·표시**에서 숨김·투명도·고립·단면을 조절합니다. 표시 조작과 시설 관리는 원본 블록·NBT를 바꾸지 않습니다. 큰 공간은 메시를 준비하는 동안 간략 형상 또는 요약 상태로 표시할 수 있습니다.

기존 수동 편집·AI 설계·대화 기록·승인·보호 장치·Undo/Redo를 유지합니다. AI 블록 변경은 미리보기와 승인 후 적용합니다. 본격적인 AI 시설 배치 확장은 v0.9.4 후속 범위입니다.

실행·단축키·진단 안내는 `RUN_WINDOWS.md`를 참고하세요.
