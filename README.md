# Ship Architect v0.9.4 개발 미리보기

이 파일은 UI·승인형 AI 내부 설계의 개발 브랜치입니다. 실제 함선·사용자 PC 검증과 공식 배포는 남아 있습니다.

1. 새 폴더에 전체를 풀고 Python 3.12 또는 3.13 기본 설치 환경에서 START_WINDOWS.cmd를 실행합니다. 첫 의존성 설치에는 인터넷이 필요합니다.
2. 기본 상단의 열기 → 공간 분석 → 선택·수정 → AI 내부 설계 → 변경 검토 → 저장 순서로 진행합니다.
3. 기존 함선에서는 확정 공간을 선택해 한국어로 내부 배치를 요청합니다. 시설의 용도·설비 분석과 미확정 경로 상태를 전달하며 실제 장치 동작은 추정하지 않습니다.
4. 변경 전후·블록 종류와 수량·범위를 확인하고 승인합니다. JSON 상세 수정도 Python 재검증을 거쳐 다시 미리보기합니다.
5. 기존 이동 경로의 폭·머리 공간을 예약하고 충돌하는 계획은 거부합니다. 장치·NBT·원본 외피·정확한 공간 제한은 기존 엔진이 검증합니다.

더 보기에서 수동 편집·모든 기능 검색·AI 연결과 재료 설정·고급/검증 작업공간·진단 ZIP을 열 수 있습니다. 고급 작업공간에서 기존 리본, 분석 엔진 비교와 편집 기능을 사용합니다.

시설 전체를 한 번에 자동 건축하는 기능은 이 미리보기에 포함되지 않습니다. 시설의 구성 확정 공간 단위로 승인형 설계를 시작합니다. Ollama 연결이 실패하면 수동 편집을 사용할 수 있습니다.
