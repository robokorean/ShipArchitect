# Ship Architect v0.9.3.12

Minecraft NeoForge 1.21.1용 Python/PySide6 함선 설계 편집기입니다.

1. ZIP 전체를 새 폴더에 풉니다. D 드라이브에서도 사용할 수 있습니다.
2. 설치된 64비트 Python 3.12/3.13 환경에서 `START_WINDOWS.cmd`를 실행합니다. 최초 패키지 설치에는 인터넷이 필요합니다.
3. **프로젝트 → .schem 열기 / 프로젝트 열기 / 새 프로젝트**를 선택합니다.

- 공간 인식: **공간 → 공간 인식**에서 기존 3D 또는 외관 복셀·메시 인식을 선택합니다. 외관 모드의 주변 지형 제외는 인식에만 적용됩니다. 분석 결과에서 병합 경계, 거부 후 재분석, JSON 및 선택 OBJ 저장을 사용할 수 있습니다. 명확한 공간만 자동 등록하고 불확실한 후보는 검토합니다.
- 표시: **보기 → 단면·표시**에서 일반 공간 불투명도 배율(80=기존 개별 알파), 후보 알파, 메시/보조 상자, 선택 공간만, 외부·미분리 영역 표시를 설정합니다. 실제 블록과 공간 형상은 변경되지 않습니다.
- 관리: 장면 탐색기에서 Ctrl/Shift로 공간을 선택하고 우클릭 또는 Delete를 사용합니다. 확인 후 공간 관리 데이터만 삭제하며 Ctrl+Z로 복원합니다. 일반 삭제와 인식 제외 등록은 별도입니다.
- 후보: 장면 탐색기 또는 하단 검토 목록에서 확인합니다. 후보 목록 삭제/제외 정리는 확정 공간이나 블록을 삭제하지 않습니다.
- 안전: 건축은 미리보기·승인 후 적용합니다. 모드 장치·NBT 보호와 정확한 공간 셀 제한을 유지합니다. 표시로 숨긴 블록은 복원 후 편집하세요.
- 진단: **도구 → 오류 진단 ZIP**. 시작 오류는 `startup.log`를 확인합니다.

큰 외부/미분리 공간은 기본 숨김·등록 차단 대상입니다. 실제 방으로 확인하려면 작은 정확한 경계로 보정하고 재검토하세요. 외형 기반 인식은 시험적이며 모든 방과 모드 충돌 형상을 정확히 자동 판정하지 않습니다.

실행 세부 안내·단축키는 [RUN_WINDOWS.md](RUN_WINDOWS.md)를 참고하세요.

최신 실행용 파일만 포함합니다. 과거 소스·개발 기록·검증 결과·개인 설계도는 포함하지 않습니다. 소스·합성 테스트·변경 이력은 GitHub `robokorean/ShipArchitect`에서 관리합니다. Python/Ollama/모드 본체를 포함한 EXE 배포판은 아닙니다.

### 저장과 신규 분석 구분

- Windows 일반 실행은 `START_WINDOWS.cmd`입니다. Python 설치 후 콘솔 없는 실행이 필요하면 `START_GUI.pyw`를 사용하세요. 오류는 startup.log에 기록됩니다.
- 공간 분석 패널에서 **저장 공간 복원**은 저장 데이터를 보여 줍니다. **완전 신규 분석**은 현재 승인된 블록 전체를 새로 읽고 기존 인식 결과와 규칙을 사용하지 않습니다.
- **공간 유지 재분석**은 사용자 검토 규칙을 적용합니다. 두 신규 분석 모두 확정 공간을 보존하고 별도 후보를 만들며, 등록은 **선택 후보 등록**으로 승인합니다.
- **저장·신규 결과 전환**과 **선택 차이 표시**에서 이전과 새 후보의 정확한 셀 차이를 볼 수 있습니다. 주황은 기존에만, 청록은 신규에만 있는 셀입니다.
- 대형 갑판 구역은 실제 갑판 접촉으로 나눈 검토 구역입니다. 숨김이 기본이며 방으로 자동 등록하지 않습니다.

이번 수정본의 두 Windows 실행 파일은 PowerShell을 호출하지 않습니다. 새 폴더에 풀어 실행하세요. 신규 분석 시 하늘에 열린 영역을 제외 후보로 분리합니다. 기존 저장 공간은 그대로 남습니다.

- .schem 직접 열기는 블록만 표시합니다. 기존 공간은 **공간 인식 → 저장 공간 복원**으로 가져옵니다. .shipproj는 저장된 작업을 복원합니다.
- **공간 → 분석 관리**에서 이름을 붙여 분석 결과를 여러 개 저장하고 다시 불러올 수 있습니다. 블록 불일치 또는 미확인 결과는 읽기 전용입니다.
- 신규 분석은 전체 일반 후보를 표시합니다. 탐색기 체크박스로 개별·그룹 표시를 바꾸거나 **공간 표시** 메뉴에서 확정/신규/변경/전체 숨김을 선택하세요.
- **공간 삭제 메뉴** 또는 탐색기 우클릭에서 확정 공간과 후보를 지울 수 있습니다. 확인 후 Ctrl+Z로 복원할 수 있으며 별도 저장한 분석은 유지됩니다.

## 구조 검증

1. `분석 → 구조 검증 → 신규 구조 분석`을 누릅니다. 기존 확정 공간과 편집을 유지합니다.
2. 오른쪽 `구조 검증`에서 외벽·갑판·실제 개구부·가상 경계·외부 연결 공기 등 원하는 레이어를 켭니다. `보기 → 2D/3D 동시 보기`와 공통 도면의 단면을 사용하면 실제 블록과 비교할 수 있습니다.
3. 후보의 속성에서 실제 외부 연결, 부분 갑판과 열린 수직 구간, 주변 설비 근거를 확인합니다. 넓은 미분리 구역은 검토 대상에 남습니다.
4. `선택에 초점`으로 해당 범위를 확인하고, `보류 / 해제` 또는 영역과 축을 지정한 뒤 `선택면 지정·교체`를 사용합니다. 수동 면은 분석 검토 표시이며 `Ctrl+Z`로 되돌릴 수 있습니다. `.shipproj` 저장 및 별도 분석 저장에 포함됩니다.
5. `도구 → 오류 진단 ZIP`의 `structure_review.jsonl`에서 실제 좌표와 구간, 근거, 생략 수 및 처리 시간을 확인합니다.

구조 레이어는 공간의 용도와 설비 작동 여부를 추정하지 않습니다. 3D는 조밀한 레이어를 샘플링하며 기록된 범위를 정확히 보는 데에는 2D 단면을 사용하세요.

### 구조 인식 엔진 비교

**분석 → 구조 검증**에서 Legacy, Structural, Hybrid를 선택합니다. Legacy는 이전 버전과 같은 공간 인식으로 기본값입니다. Structural은 국소 바닥·천장과 벽 지지를 사용합니다. Hybrid 0.9.3.7은 주변 개구에 제한적으로 빈칸을 추가하고 기존의 물리 근거가 강한 경계를 재확인해 보존합니다.

**Legacy와 비교**는 동일 설계도에서 초기 기준과 신규 결과를 계산합니다. 하단 공간 검토에 겹치는 후보의 정확한 복셀 수가 나옵니다. 공간 인식의 이전/신규 전환과 차이 표시를 사용할 수 있습니다. 개방형 시설과 대형 후보는 검토 상태를 확인하세요.

수동 가상면을 저장한 뒤 구조 엔진으로 보호 재분석하면 해당 면을 가로지르는 공기 셀 간의 그래프 연결을 제한합니다. 현재 블록 버전에 해당하는 경계만 적용합니다. 물리적인 공기 연결이나 블록 데이터는 유지됩니다.

Hybrid 0.9.3.8은 실제 연결 갑판의 경계를 영역 확장에 반영하고, 지붕이 빠졌지만 높은 벽으로 둘러싸인 곳을 별도 검토합니다. 두 분석 화면의 엔진 선택은 공유·저장됩니다.

### 통합 공간 인식 (0.9.3.9)

**분석 → 구조 검증 → 통합 · 0.9.3.9**를 선택해 분석합니다. 기존 Legacy 및 Hybrid 3.7/3.8은 비교용으로 유지되며 기존 기본값은 Legacy입니다. 통합은 두 방식에서 발견된 실제 빈 셀을 한 번씩만 분류합니다. 실제 바닥·천장과 연결 갑판의 근거가 있는 구역은 개별 검토 후보로 분리합니다.

구조 검증의 **넓은 탐색 복원 셀** 레이어로 Legacy에서만 찾은 실제 빈 셀을 확인할 수 있습니다. 공간 표시의 **복원된 탐색 공간**과 **미확정·제외 후보** 모드에서는 관련 후보를 2D·3D에서 확인할 수 있습니다. 낮은 자투리 공간은 모델에 보존되며 자동 건축 공간으로 등록되지 않습니다.

### 프로젝트 탐색기와 통합 정밀 분석

**분석 → 구조 검증 → 통합 정밀 · 0.9.3.10**을 고르고 **신규 구조 분석**을 실행합니다. 3.9는 비교 엔진으로 남아 있습니다. 새 분석에서는 인접 공간 조각, 잔여 공기, 실제 갑판 사이 분할 및 설비·이동 후보를 확인할 수 있습니다. 판정이 필요한 공간은 우클릭 **후보 확정·등록**으로 등록합니다.

탐색기의 첫 체크박스는 표시, 오른쪽 **선택** 체크박스는 선택입니다. Ctrl / Shift나 **검색 결과 선택**도 사용할 수 있습니다. 2D와 3D에서 겹친 대상을 연속 클릭하면 대상이 순환합니다. F 또는 더블클릭으로 초점을 이동하고 /로 고립합니다. **단면·내부 관찰**에서 강조 색상과 외벽 너머 표시를 조절할 수 있습니다.

탐색기 우클릭 또는 공간 리본의 **탐색기 데이터 삭제**에서 선택, 그룹, 검색 결과, 표시 중인 대상과 전체 분석 데이터를 각각 정리할 수 있습니다. 일반 삭제는 재분석에서 다시 발견될 수 있습니다. **삭제 및 재분석 제외**는 같은 위치의 설비·경로나 동일 복셀 형상을 제외 목록에 기록합니다. Ctrl+Z / Ctrl+Y로 작업을 되돌리거나 다시 적용합니다. 등록 자료와 제외 규칙은 프로젝트에 저장됩니다.

### 공간 표시 및 그래픽 설정

**도구 → 그래픽 설정**에서 자동·저사양·균형·고품질·최고품질, 목표 FPS, 주변·선택 면 예산과 캐시 상한을 조절합니다. 목표 FPS는 조작 갱신 간격입니다. 활성 렌더러는 QPainter + CPU이며 OpenGL을 요청한 경우 호환 렌더러를 표시합니다.

상태 표시줄의 **정밀 / 간략 / 요약**으로 현재 뷰의 표시 방식을 확인하세요. 요약 점은 실제 후보 내부의 좌표를 나타냅니다. 정확한 형상과 역선택은 정밀 표시, 2D 단면과 탐색기에서 확인하세요. 활성 공간은 청크가 준비되는 순서대로 정밀해집니다. 대량 선택의 범위는 탐색기의 선택 수에서 확인합니다. 여러 항목의 동시 강조는 **다중 강조**로 켭니다.

**보기 → 작업 표시 프리셋**에서 외형 설계, 내부 공간 설계, 설비 배치, 이동 경로 검토, 공간 인식 검증을 전환합니다. 외부 공기는 **단면·표시**에서 명시적으로 켭니다. 사용자 표시를 저장하거나 프리셋 전 상태를 복원할 수 있습니다. 공간 인식 엔진 이름은 **통합 정밀 · 0.9.3.10**입니다.

### 한 번에 공간 분석

프로젝트 리본에서 **공간 분석**을 누르면 통합 정밀 엔진으로 전체를 스캔하고, 주요·보조·이동 공간을 표시합니다. 부속 조각은 상위 공간에 접어 두며 기타 후보와 숨겨진 항목도 ID로 검색할 수 있습니다. 선택 속성에서 숨김, 단면, 요약, 대기, 실패를 확인하고 **이 공간 임시 보기**를 사용할 수 있습니다.

**공간 → 분석 옵션 → 고급 분석·복원**에 기존 비교, 저장 결과 복원, 크기·활용도 필터가 있습니다. 분류는 검토용이며 장치의 동작이나 실제 통행을 확정하지 않습니다.

공간을 우클릭해 소속을 바꾸거나 그룹에서 분리할 수 있습니다. 확정 공간끼리 합칠 때 연결된 빈 셀을 검사하고, 분할은 2D 또는 3D에서 정한 영역과 겹치는 셀을 사용합니다. 색으로 결과를 미리 본 뒤 승인하고 Undo로 복구할 수 있습니다.
