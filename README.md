# Ship Architect v0.9.4

Minecraft NeoForge 1.21.1용 승인형 함선 내부 설계·편집기입니다.

1. ZIP 전체를 새 폴더에 풀고 64비트 Python 3.12 또는 3.13을 설치한 뒤 `START_WINDOWS.cmd`를 실행합니다. 첫 의존성 설치에는 인터넷이 필요합니다. 자세한 실행·단축키는 `RUN_WINDOWS.md`를 참고하세요.
2. 상단 **열기 → 공간 분석 → 선택·수정 → AI 내부 설계 → 변경 검토 → 저장** 순서로 작업합니다. `.shipproj`는 기존 공간·편집을 복원하고, `.schem` 직접 열기는 이전 공간을 자동 적용하지 않습니다.
3. 왼쪽 탐색기에서 확정 공간 또는 사용자가 확인한 시설을 선택합니다. 여러 공간을 하나의 시설로 묶어도 원래 공간 ID와 실제 형태는 유지됩니다. 시설 전체 AI 설계는 구성 공간의 정확한 셀 합집합 안에서만 허용합니다.
4. Ollama에서 `ollama pull qwen3:4b` 후 서버를 실행하고 **연결·사용 재료 설정**에서 연결 상태와 모델을 확인합니다. 한국어 요청을 입력하면 AI는 설계 JSON을 제안하고 Python이 좌표·재료·충돌·보호·기존 경로를 검사합니다. 연결 실패 시 수동 편집은 계속 사용할 수 있습니다.
5. **변경 검토**에서 전후 2D/3D·실제 블록 종류와 수량·범위를 확인하고 **확인한 변경 승인·적용**을 누릅니다. 요청 수정·재생성 및 설계 JSON/재료 수정도 새 검증과 미리보기가 필요합니다. AI의 완료 주장만으로 적용하지 않습니다.

시설 용도와 미확정 후보·경로는 자동 확정하지 않습니다. 외부·제외·잘린 미해결 후보나 사라진 구성 공간이 포함된 시설은 설계를 차단합니다. 모드 장치의 실제 동작·게임 내 충돌은 검증하지 않으므로 별도 확인이 필요합니다.

**더 보기**에서 기존 수동 편집, 모든 기능 검색, 고급 작업공간, 2D/3D 동시 보기, 작업공간 저장, 대화·진단 기능을 엽니다. 진단 ZIP은 기존 고급 작업공간의 **도구 → 오류 진단 ZIP** 또는 **더 보기 → 오류 진단 ZIP**에서 내보냅니다.

이 ZIP에는 최신 실행 필수 파일만 포함합니다. Ollama·모델·Python·개인 설계도·개발 검증 자료는 포함하지 않습니다. Linux에서는 Python 3.12+에서 `python -m pip install -r requirements.txt` 후 `python START_GUI.pyw`를 실행합니다.
