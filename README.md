# Ship Architect v0.9.3.2

Minecraft NeoForge 1.21.1용 Python/PySide6 함선 설계 편집기입니다.

1. ZIP 전체를 새 폴더에 풉니다. D 드라이브에서도 사용할 수 있습니다.
2. 설치된 64비트 Python 3.12/3.13 환경에서 `START_WINDOWS.cmd`를 실행합니다. 최초 패키지 설치에는 인터넷이 필요합니다.
3. **프로젝트 → .schem 열기 / 프로젝트 열기 / 새 프로젝트**를 선택합니다.

- 공간 인식: **공간 → 공간 인식**에서 기존 3D 또는 외관 복셀·메시 인식을 선택합니다. 명확한 공간만 자동 등록하고 불확실한 후보는 검토합니다.
- 표시: **보기 → 단면·표시**에서 일반 공간 불투명도 배율(80=기존 개별 알파), 후보 알파, 메시/보조 상자, 선택 공간만, 외부·미분리 영역 표시를 설정합니다. 실제 블록과 공간 형상은 변경되지 않습니다.
- 관리: 장면 탐색기에서 Ctrl/Shift로 공간을 선택하고 우클릭 또는 Delete를 사용합니다. 확인 후 공간 관리 데이터만 삭제하며 Ctrl+Z로 복원합니다. 일반 삭제와 인식 제외 등록은 별도입니다.
- 후보: 장면 탐색기 또는 하단 검토 목록에서 확인합니다. 후보 목록 삭제/제외 정리는 확정 공간이나 블록을 삭제하지 않습니다.
- 안전: 건축은 미리보기·승인 후 적용합니다. 모드 장치·NBT 보호와 정확한 공간 셀 제한을 유지합니다. 표시로 숨긴 블록은 복원 후 편집하세요.
- 진단: **도구 → 오류 진단 ZIP**. 시작 오류는 `startup.log`를 확인합니다.

큰 외부/미분리 공간은 기본 숨김·등록 차단 대상입니다. 실제 방으로 확인하려면 작은 정확한 경계로 보정하고 재검토하세요. 외형 기반 인식은 시험적이며 모든 방과 모드 충돌 형상을 정확히 자동 판정하지 않습니다.

실행 세부 안내·단축키는 [RUN_WINDOWS.md](RUN_WINDOWS.md)를 참고하세요.

최신 실행용 파일만 포함합니다. 과거 소스·개발 기록·검증 결과·개인 설계도는 포함하지 않습니다. 소스·합성 테스트·변경 이력은 GitHub `robokorean/ShipArchitect`에서 관리합니다. Python/Ollama/모드 본체를 포함한 EXE 배포판은 아닙니다.
